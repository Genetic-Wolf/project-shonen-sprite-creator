PROJECT SHONEN SPRITE CREATOR v0.11.0

SINGLE-ENTRY PRODUCTION UI MILESTONE

The application now formally standardizes one normal artist entry point:
ProjectShonenSpriteCreator.exe

The production workspace is organized around five persistent concepts:
1. Characters
2. Reusable Pieces
3. Body Masters
4. RPG Maker MZ
5. Settings

The already-working specialist editors remain available behind these pages during migration, so functionality is preserved while the UI is consolidated.

NO-CODE REQUIREMENT
Artists are not expected to use Python, terminals, JSON, asset IDs, source code, or RPG Maker filename conventions.

BODY MASTER REQUIREMENT
Artists can create new Female, Male, Youth, Child, or Custom master bodies, including Small, Standard, Tall, Athletic, Chubby, Heavy, or custom body types. New body artwork remains independent and artist-authored in Clip Studio Paint.

DATA COMPATIBILITY
Existing library.json and master_registry.json structures are preserved. This pass does not reset previously created assets or masters.

RPG MAKER
The safe install workflow and timestamped replacement backups from v0.10 remain part of the production architecture.

CLIP STUDIO
Layered ORA workspaces and transparent PNG interchange remain the art pipeline.
