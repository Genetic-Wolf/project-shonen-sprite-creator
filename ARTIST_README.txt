PROJECT SHONEN SPRITE CREATOR — WINDOWS ARTIST EDITION

HOW TO START
1. Extract the complete ZIP to a normal folder.
2. Double-click ProjectShonenSpriteCreator.exe.

You may also double-click:
Launch Project Shonen Sprite Creator.bat

YOU DO NOT NEED
- Python
- pip
- Visual Studio
- a terminal
- a code editor
- JSON editing

If ProjectShonenSpriteCreator.exe is missing, the package is incomplete. Do not install Python as a workaround.

The application stores your character projects, artist workspaces, exports and automatic backups inside the portable Project Shonen Sprite Creator folder.
