PROJECT SHONEN SPRITE CREATOR v0.8.0

NEW: VISUAL BODY MASTER CREATION

Artists can now create a body family without editing code or registry files.

EXAMPLE
1. Launch New Body Master Wizard.
2. Choose Female.
3. Choose Chubby.
4. Display name becomes Female Chubby.
5. Choose Female Standard as a visual reference.
6. Choose the relevant bust-fit profile.
7. Click Create Body Master Workspace.

The program:
• assigns the permanent master ID;
• registers the body;
• creates TV, FG, TVD, SV and Variation output records;
• generates five layered Clip Studio-compatible ORA workspaces;
• provides canonical grids;
• includes the parent body as a non-export reference layer;
• creates transparent DRAW layers;
• marks every new output DRAFT + UNLOCKED.

The artist then draws the actual new canonical body in Clip Studio, exports each base PNG, and uses Master Template Manager to replace, approve and lock each output.

IMPORTANT
A parent master is an alignment/reference source only. The new body must have its own artwork. This prevents Female Chubby, Male Athletic, Heavy, Tall, etc. from becoming crude scaled copies of Standard.
