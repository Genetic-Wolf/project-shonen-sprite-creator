PROJECT SHONEN SPRITE CREATOR v0.16.0

MULTI-OUTPUT CHARACTER PRODUCTION

The integrated Character Builder now supports live readiness/preview for:
• TV — Walking
• FG — Face
• TVD — Downed
• SV — Side-view battle

OUTPUT PREVIEW
The artist can switch the live preview between TV, Face, Downed and SV.
The program displays an appropriate representative frame/cell rather than forcing every output through the Walking preview.

PRODUCTION GATE
Character exports now require the corresponding body-master output to be both:
• Approved
• Locked

Draft or revision geometry cannot silently become production character art.

MULTI-OUTPUT EXPORT
Artists can export the currently selected representation or use Export All Ready Outputs.
Incomplete representations are skipped and reported instead of producing broken files.

RPG MAKER STAGING
Outputs are staged into the existing TV, FG, TVD and SV export folders for safe installation through the integrated RPG Maker MZ page.

This pass moves the creator from Walking-only character assembly toward a complete RPG Maker character-art pipeline.
