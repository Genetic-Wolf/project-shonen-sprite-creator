PROJECT SHONEN SPRITE CREATOR — v0.18.0 RELEASE CANDIDATE PREPARATION

This source package is prepared for the Windows Release Candidate build.

IMPORTANT:
The Female Standard and Male Standard Walking/TV masters are intentionally reset to Draft/Unlocked.
The v0.17 audit had restored their missing paths using an unsafe cross-master fallback. v0.18 rejects that recovery rather than allowing visually incorrect geometry to become canonical.

Before production character export:
1. Open Body Masters.
2. Import/confirm the correct Walking master artwork.
3. Visually inspect it.
4. Approve + Lock it.

Normal artists should ultimately receive the packaged Windows Artist Edition, not the development source package or build scripts.
