PROJECT SHONEN SPRITE CREATOR v0.15.0

VISUAL CHARACTER-ASSEMBLY HARDENING

LIVE PREVIEW
The integrated Character Builder now renders a live enlarged pixel-perfect preview of the down-facing idle frame.

SEARCH
Compatible reusable pieces can be searched by name or category.

LAYER STACK
Selected components now have an explicit visible layer stack.
Artists can move a selected component up or down to resolve special layering needs and remove it without rebuilding the character.

COMPATIBILITY
Only pieces registered to the selected body master appear in the normal component browser.

READINESS
The preview reports incomplete Walking assets, missing files and wrong-size layers.
Invalid characters are blocked from Walking export rather than silently producing broken graphics.

EXPORT
The exported RPG Maker MZ $ walking sheet preserves the canonical 144x192 canvas and current visual layer order.

NEXT HARDENING TARGET
Extend the same assembled-character workflow to Face, TVD and SV outputs, add component thumbnails/category filters, and tighten production readiness around approved/locked body masters.
