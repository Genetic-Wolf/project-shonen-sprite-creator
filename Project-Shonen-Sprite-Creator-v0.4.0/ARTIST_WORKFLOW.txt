PROJECT SHONEN SPRITE CREATOR v0.4.0
ARTIST WORKFLOW — NO CODING REQUIRED

1. Launch the packaged ProjectShonenSpriteCreator application.
2. Select Male Standard or Female Standard.
3. Select the component category being created.
4. Create an artist workspace/template for that category.
5. Open the generated .ORA in Clip Studio Paint. You may immediately Save As .CLIP for normal CSP work.
6. Draw on the dedicated component layer while preserving the locked 144x192 canvas and 3x4 TV grid.
7. Keep the canonical base and guides as reference only.
8. Hide the base and guides before export.
9. Export the new component as a transparent PNG at exactly 144x192.
10. Import that PNG into Sprite Creator under the same category/body master.
11. Sprite Creator validates size/body compatibility, assigns the internal asset ID, and adds it to the reusable library.
12. Assemble characters visually from reusable pieces.
13. Configure the RPG Maker MZ project once with RPG Maker Setup.
14. Export Character. The walking sheet is saved locally and copied automatically to img/characters when a project is configured.

ARTIST DOES NOT NEED TO EDIT:
- Python
- JSON
- asset IDs
- RPG Maker generator filenames
- internal folders
- command-line scripts

SOURCE/BUILD NOTE:
The source package can still be run by a developer with Python. The artist-facing Windows distribution is intended to be compiled as ProjectShonenSpriteCreator.exe with all runtime dependencies bundled.
