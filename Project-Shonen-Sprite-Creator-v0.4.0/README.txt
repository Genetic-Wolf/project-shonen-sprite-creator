PROJECT SHONEN SPRITE CREATOR v0.1.0

Windows prototype. Requires Python 3 and Pillow for this development build.
Launch: double-click Launch_Project_Shonen_Sprite_Creator.bat

Implemented:
- Male/Female Standard canonical bases
- animated 4-direction TV preview
- independent component library
- transparent PNG import validation (144x192)
- body compatibility check
- layer compositing
- save/load character definitions
- RPG Maker MZ $ single-character TV export
- bundled Clip Studio/OpenRaster artist masters

Next production milestone:
- package as a true dependency-free Windows .exe
- thumbnail asset browser and recoloring
- Face/TVD/SV/Variation pipelines
- MZ generator naming/install automation
- richer body-family compatibility and component variants
